Understanding adversarial attacks

An adversarial attack takes an input your model already classifies correctly and nudges it — often by an amount too small to notice — until the model gets it wrong. AO8 runs three of the most common attacks so you can see exactly how fragile your model is. Drag the controls below to build intuition before you read the numbers on your own report.

THE BUDGET

Epsilon (ε)

Epsilon is the leash on an attack. It caps how far any single input is allowed to move before the attacker has to stop — the maximum size of the perturbation, measured in the same units as your input features. A tiny epsilon means the attacker can only nudge a point slightly; a large epsilon lets them drag it much further from where it started.

FGSM and PGD both work inside an epsilon budget you choose. C&W is different — instead of being told how far it's allowed to move, it searches for the smallest distortion that still fools the model, so the "perturbation (L2)" column in your report is really C&W discovering its own effective epsilon per sample.

Drag the point, or drag the slider. The shaded disc is everywhere the attacker is allowed to push it. Points that cross the dashed boundary have flipped class.

FAST GRADIENT SIGN METHOD

FGSM

FGSM takes a single step in the direction that increases the model's loss the fastest, scaled by epsilon. It's cheap to compute — one gradient pass — which makes it a fast sanity check, but it's also the weakest of the three attacks AO8 runs. A model that survives FGSM hasn't proven much; a model that fails FGSM is definitely fragile.

FGSM only ever takes one step, straight to the edge of the epsilon budget, in the single worst direction it can compute.

PROJECTED GRADIENT DESCENT

PGD

PGD repeats the FGSM step multiple times, projecting the result back into the allowed epsilon-ball after each step so the perturbation never grows too large. It's the standard benchmark in adversarial ML research — if your model holds up under PGD, that's a meaningful robustness signal.

Each small step is projected back inside the disc, so PGD explores the whole budget instead of committing to one direction — usually finding a better flip than FGSM at the same ε.

CARLINI & WAGNER

C&W

C&W searches for the smallest possible perturbation that still flips the model's prediction, rather than working within a fixed epsilon budget. It's slower to run than FGSM or PGD, but it tells you the true minimum distortion an attacker would need — useful for understanding worst-case exposure.

Instead of a fixed budget, C&W tightens the disc step by step until it finds the smallest one that still crosses the boundary — that radius is the number you see in "perturbation (L2)".

AFTER THE REPORT

Using safe values

When an attack finds a version of an input that flips your model's prediction, AO8 also records a safe value for that sample: a version of the same input, at the same perturbation distance, that the model still classifies correctly. Comparing the two shows you exactly which features an attacker leaned on, and which version of the input your model can be trusted with.

01

Download the set for an attack

On your results page, each attack with flipped samples gets a "Download safe values" button. This gives you a file matched row-for-row with the flipped-samples table, so you can line up original → adversarial → safe for the same sample index.

02

Diff against the flipped input

For any row, subtract the safe value from the adversarial one. The features with the largest difference are the ones the attack actually exploited — cross-reference against "most perturbed features" in the same row.

03

Feed it back into training

Safe values are valid, correctly-labeled inputs near the decision boundary. Adding them to your training set (or using them for adversarial fine-tuning) tends to push the boundary away from your real data without needing new labels.

04

Re-run and compare

After retraining, run the same attack again. A shrinking gap between clean and robust accuracy — or a rising minimum perturbation for C&W — is the signal that the safe values actually helped.
